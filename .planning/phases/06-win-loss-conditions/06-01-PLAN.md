# Implementation Plan 06-01: Win / Loss Conditions

## Goal Description
Implement the logic to detect when a player has lost all their bases and transition to a Game Over screen.

## User Review Required
> [!IMPORTANT]
> - **Game Over Screen**: A simple full-screen overlay or transition to a dedicated `GameOverScreen` will be implemented.
> - **Win Condition**: The game ends when all bases of ONE player are destroyed or captured (leaving them with 0 bases).

## Proposed Changes

### core/src/main/java/com/militopia/data/GameState.java
- **[MODIFY]** Ensure `p1BaseCount` and `p2BaseCount` are correctly tracked or add a method to recalculate them from the engine.

### core/src/main/java/com/militopia/screen/GameScreen.java
- **[MODIFY]** In `render()` or at the end of a turn, check if `gameState.p1BaseCount == 0` or `gameState.p2BaseCount == 0`.
- **[MODIFY]** If a win condition is met, call `game.setScreen(new GameOverScreen(game, winnerID))`.

### core/src/main/java/com/militopia/screen/GameOverScreen.java
- **[NEW]** create a new screen to display the winner and a button to return to the main menu.

### core/src/main/java/com/militopia/systems/CombatSystem.java
- **[MODIFY]** Ensure that when a structure is destroyed, if it was a Base, the `pXBaseCount` is decremented.
- **[MODIFY]** If it was captured, ensure counts are updated for both players.

## Verification Plan

### Automated Tests
- Build verification: `./gradlew core:compileJava`.

### Manual Verification
1. **Victory**: Destroy the final enemy base and verify that the Game Over screen appears with the correct winner.
2. **Menu Return**: Click "Return to Menu" and verify it goes back to `MenuScreen`.
