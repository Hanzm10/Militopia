    Create `core/src/test/java/com/militopia/systems/CombatRosterTest.java` in package `com.militopia.systems`.

    The test needs a UnitFactory instance. UnitFactory constructor requires `(PooledEngine, AssetManager, GameMap, GameState)`. Pass `null` for AssetManager (texture loading is skipped in createUnit stat assignment — it only fails on texture region lookup which happens after stats are set, but the stat assignment completes). However, createUnit calls `engine.addEntity` which requires a working engine, and it calls `assetManager.getUnitRegions(unitType)` which will NPE.

    Alternative approach: Do NOT call createUnit. Instead, test cost consistency by comparing getUnitCost against a hardcoded expected-cost map. This is simpler and avoids the AssetManager dependency entirely. The hardcoded values serve as the source of truth — if either createUnit or getUnitCost drifts, a human reviewer will catch the mismatch against the test constants.

    Actually, the strongest guard is to test getUnitCost values match the known correct costs. If someone changes createUnit costs without updating getUnitCost, the test alone won't catch it — but the existing comment "Must match cost in createUnit" plus this test catching getUnitCost drift is the practical guard.

    Implementation:
    ```java
    package com.militopia.systems;

    import com.badlogic.ashley.core.PooledEngine;
    import com.militopia.data.GameState;
    import com.militopia.factories.UnitFactory;
    import com.militopia.map.MapGenerator;
    import org.junit.jupiter.api.BeforeEach;
    import org.junit.jupiter.api.Test;

    import java.util.LinkedHashMap;
    import java.util.Map;

    import static org.junit.jupiter.api.Assertions.*;

    public class CombatRosterTest {
        private UnitFactory unitFactory;

        @BeforeEach
        public void setup() {
            PooledEngine engine = new PooledEngine();
            MapGenerator.GameMap gameMap = new MapGenerator.GameMap(10, 10);
            GameState gameState = new GameState(12345L, "TestSave", 10, 10);
            unitFactory = new UnitFactory(engine, null, gameMap, gameState);
        }

        @Test
        public void testCostConsistency() {
            // Expected costs — canonical source of truth
            Map<String, Integer> expected = new LinkedHashMap<String, Integer>();
            expected.put("RECRUIT", 2);
            expected.put("RANGER", 5);
            expected.put("SNIPER", 8);
            expected.put("TANK", 15);
            expected.put("JUGGERNAUT", 0);
            expected.put("RECON_DRONE", 4);
            expected.put("SUICIDE_DRONE", 7);
            expected.put("APACHE", 18);
            expected.put("B2", 0);
            expected.put("GUNBOAT", 6);
            expected.put("DESTROYER", 13);
            expected.put("CARRIER", 25);
            expected.put("SUBMARINE", 0);

            for (Map.Entry<String, Integer> entry : expected.entrySet()) {
                assertEquals(entry.getValue().intValue(), unitFactory.getUnitCost(entry.getKey()),
                    "Cost mismatch for " + entry.getKey());
            }
        }

        @Test
        public void testSummonableUnitCount() {
            String[] allUnits = {"RECRUIT", "RANGER", "SNIPER", "TANK", "JUGGERNAUT",
                "RECON_DRONE", "SUICIDE_DRONE", "APACHE", "B2",
                "GUNBOAT", "DESTROYER", "CARRIER", "SUBMARINE"};
            int summonable = 0;
            for (String unit : allUnits) {
                if (unitFactory.getUnitCost(unit) > 0) {
                    summonable++;
                }
            }
            assertEquals(10, summonable, "Expected exactly 10 summonable units (cost > 0)");
        }
    }
    ```

    Use Java 8 compatible syntax (no var, no Map.of). Use LinkedHashMap for deterministic iteration order.
