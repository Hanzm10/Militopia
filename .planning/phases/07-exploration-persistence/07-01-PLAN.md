# Phase 7: Exploration & Persistence

## Goal
Add map exploration rewards, resource-specific construction constraints, and turn-state persistence.

## Feature Breakdown

### 7.1 Ruins Interaction (`RUINS`)
- **Trigger**: Unit enters a `RUINS` tile.
- **Logic**: Random selection from the Scavenge table:
    - `+15 Funding`
    - `+1000 XP`
    - `Spawn Recon Drone` (Initial move toward enemy base)
    - `Spawn Sniper` (On tile)
    - `Spawn Destroyer` (Adjacent water)

### 7.2 Oil Derrick Constraints (`OIL`)
- **Logic**: Update `BuildMenu` to only allow `OIL_DERRICK` on tiles containing an `OIL_RESERVOIR` object.
- **UI**: Visual feedback in the build menu when hovering over invalid tiles.

### 7.3 Movement Persistence
- **Requirement**: `hasMoved` and `hasActed` flags must be saved to the JSON file.
- **Impact**: Players cannot circumvent "once per turn" rules by reloading the game mid-turn.
