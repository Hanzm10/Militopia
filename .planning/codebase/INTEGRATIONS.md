# External Integrations
_Last updated: 2026-03-26_

## Summary
Militopia has no network or third-party API integrations. All external interactions are local: asset files on disk, JSON save files written to the local filesystem, and audio loaded from the assets directory. The only "external" libraries are libGDX ecosystem components resolved from Maven Central and JitPack.

## APIs & External Services

**None.** No HTTP clients, no REST APIs, no third-party cloud services, no authentication providers.

## Data Storage

**Save Files (local filesystem):**
- Format: JSON serialized via libGDX's built-in `com.badlogic.gdx.utils.Json`
- Location: `assets/saves/<saveName>.json` (resolved as `Gdx.files.local("saves/<name>.json")`)
- Written by: `core/src/main/java/com/militopia/managers/SaveManager.java`
- Read by: `core/src/main/java/com/militopia/screen/LoadGameScreen.java`
- Schema: `core/src/main/java/com/militopia/data/GameState.java`
  - Contains: `seed`, player names, turn count, XP/funding, unit list, structure list, animal list, map object grid

**No database.** No ORM, no SQL, no embedded DB.

**No cloud/remote storage.**

## Asset Pipeline

All game assets are flat files bundled into the JAR and loaded via libGDX's `AssetManager`.

**Asset root:** `assets/` (mounted as working directory at runtime via `run { workingDir = rootProject.file('assets').path }`)

**Asset manager:** `core/src/main/java/com/militopia/managers/AssetManager.java`
- Wraps `com.badlogic.gdx.assets.AssetManager`
- Loads all textures synchronously via `finishLoading()` at startup
- Registers FreeType loaders for `.ttf` fonts

**Asset categories:**
| Directory | Content |
|---|---|
| `assets/tiles/` | Terrain tile sprites (grass, water, sand, mountain, fog) |
| `assets/units/` | Unit sprites (left/right facing per unit type) |
| `assets/displays/` | Unit/animal info panel display images |
| `assets/bases/` | Base structure sprites (lvl 1–10, blue/red variants) |
| `assets/structures/` | Economy structures (factory, port, solar, oil, etc.) |
| `assets/objects/` | Map objects (trees, ruins, oil, animals) |
| `assets/ui/` | HUD icons and UI elements |
| `assets/game-system/` | Background image, game font TTF |
| `assets/saves/` | Runtime save files (JSON) |
| `assets/audio/sfx/` | Sound effects (loaded on demand) |
| `assets/audio/bgm/` | Background music (streamed) |

**Asset manifest:** `assets/assets.txt` — auto-generated by the `generateAssetList` Gradle task before every build. Lists all asset file paths.

## Audio System

**Implementation:** `core/src/main/java/com/militopia/managers/AudioManager.java` (singleton)

- **SFX:** loaded on demand from `assets/audio/sfx/` via `Gdx.audio.newSound()`; cached in memory after first load
- **BGM:** streamed from `assets/audio/bgm/` via `Gdx.audio.newMusic()`; only one track plays at a time
- **Rate limiting:** max 5 identical SFX per frame to prevent audio blowing
- **No external audio service or library** — purely libGDX audio APIs

## ECS Integration (Ashley)

**Library:** `com.badlogicgames.ashley:ashley:1.7.4`

**Engine:** `com.badlogic.ashley.core.PooledEngine` — instantiated in `GameScreen`, owns all entities

**Component → System data flow:**

| Components | Consumed by Systems |
|---|---|
| `GridPositionComponent`, `StatsComponent`, `TypeComponent` | Most systems; also read by `SaveManager` |
| `MovementComponent` | `MovementSystem` |
| `AnimationComponent`, `SpriteAnimationComponent`, `DeathAnimComponent` | `AnimationSystem` |
| `TextureComponent` | `UnitRenderSystem`, `MapRenderSystem` |
| `FacingComponent` | `UnitRenderSystem` |
| `FloatingTextComponent` | `FloatingTextSystem` |
| `AbilitiesComponent` | `AbilityStatusSystem`, `CombatSystem` |

**Systems registered (in `GameScreen`):**
- `MapRenderSystem` — tile rendering
- `UnitRenderSystem` — unit sprite rendering
- `AnimationSystem` — bounce/death animations
- `FloatingTextSystem` — damage numbers
- `MovementSystem` — unit movement
- `CombatSystem` — attack resolution
- `FogSystem` — fog of war visibility
- `AbilityStatusSystem` — ability cooldown tracking
- `StructureEconomySystem` — per-turn resource income
- `StructurePlacementSystem` — building placement
- `ScavengeSystem` — animal scavenging
- `EffectSystem` — visual effects
- `WinConditionSystem` — win/loss detection

## UI Framework

**libGDX Scene2D** — all UI built with `Stage`, `Table`, `Label`, `TextButton`, `ScrollPane`, `TextField` from `com.badlogic.gdx.scenes.scene2d`

**Skin:** constructed programmatically in `MilitopiaGame.create()`, no external `.json` skin file
- Font injected from `AssetManager.getFont()` (FreeType-rendered TTF)
- Drawable styles built from a 1x1 white pixel texture with color tinting

## Font Rendering

**Library:** `gdx-freetype` (libGDX extension)

- Font file: `assets/game-system/game_font.ttf`
- Size: 24px, Linear filter
- Loaded via `FreeTypeFontGeneratorLoader` + `FreetypeFontLoader` registered on the `AssetManager`

## Map Generation

**Custom implementation — no external library:**
- `core/src/main/java/com/militopia/map/MapGenerator.java` — procedural map generation seeded by `GameState.seed`
- `core/src/main/java/com/militopia/map/SimpleNoise.java` — custom noise implementation (not Simplex/Perlin library)

## Build / Distribution

**Repositories used:**
- `mavenCentral()` — primary dependency source
- `mavenLocal()` — fallback for local installs
- `https://central.sonatype.com/repository/maven-snapshots/` — snapshot builds
- `https://jitpack.io` — declared but no JitPack dependencies currently active
- `gradlePluginPortal()` — Construo plugin

**No CI/CD pipeline detected.** No GitHub Actions, no Jenkinsfile, no CircleCI config found.

## Monitoring & Observability

**Error Tracking:** None (no Sentry, Crashlytics, etc.)

**Logging:** Custom `GameLogger` utility at `core/src/main/java/com/militopia/utils/GameLogger.java`
- Category-based: `GameLogger.UI`, etc.
- Wraps `System.out.println` / similar; no external logging framework

## Webhooks & Callbacks

**None.** No inbound or outbound HTTP webhooks.
